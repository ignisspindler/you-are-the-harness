# Your tools
*What an AI tool can do, by category, and how to find out which of these yours can.*

This course never names a product. Tools change monthly and every learner has a different one. What matters is capability. Every capability below serves a node of the Semantifacturing loop, and every one of them is either present or absent in the tool in front of you. Find out which.

## The capabilities

```

──────────────────────────────────────────────────────────────────────────
Reads your files      Can open documents, notes and drafts       SCAFFOLD
                      in a folder you point it at

Writes files          Can create and update files on your        REFINE
                      machine, which is how this course
                      saves your work

Searches the web      Can look things up outside the             ASSESS
                      conversation and fetch a page

Remembers across      Keeps something from one session to        INTENTION
sessions              the next without you pasting it            SCAFFOLD

                      document store, a code repository

                      slide deck, a spreadsheet

                      morning, or every week, without you

```

## Find out what yours can do

Ask it. Four questions, at the start of any session in a tool you are not sure about:

> Can you read the files in this folder?
> Can you create and edit files here?
> Can you search the web right now?
> Do you remember anything from our last session?

A tool that can do the first two is what this course calls **file-capable**. The tutor writes your workbook for you. A tool that cannot is a **browser chat**: you paste in and copy out, following `no-ai-tool-nearby.md`. Both work. Only the mechanics differ.

If the answer to any question is uncertain, treat it as no. Tools sometimes describe capabilities they do not have in the mode you are using.

## What differs, and why it matters

```
                          FILE-CAPABLE TOOL       BROWSER CHAT
──────────────────────────────────────────────────────────────────
Your artifacts            written to workbook/    you save them yourself
Resuming a session        automatic               you paste progress.md in
History of your files     workbook/history/       your own copies
Source material           the tool reads it       you paste it in
Verifying a claim         web search, if present  web search, if present;
                                                  otherwise you check by hand
```

The one that matters most is the last row. If your tool cannot search the web, Airlock question 5 ("does anything outside this conversation support it?") has to be answered by you, in a different window. Do not skip it because the tool cannot do it.

## The loop, by tool

```
  LOOP NODE        REACH FOR
  ─────────────────────────────────────────────────────
  INTENTION        your intent file, your Constitution
  SCAFFOLD         file reading, project systems, memory
  GENERATE         document creation, the six roles
  ASSESS           web search, the Airlock, your own checks
  REFINE           file writing, the Change Ledger, schedules
  PARTICIPATE      none of these. Close the tool. Go.
  ─────────────────────────────────────────────────────
```
