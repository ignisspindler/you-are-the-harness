# Start here

You are about to take a course that is taught by whatever AI tool you already use. There is no video, no slides, and no lecture. Your AI reads the lesson files in this folder and teaches you in conversation, using a project you actually care about as the material. Everything you build is saved here, in `workbook/`, as ordinary files you can open, edit and keep.

## Who this is for

It is for anyone who uses AI for real work and wants to stay in charge of it. No coding, no prior course, no technical background. If you have used a chat assistant for anything that mattered, you are ready.

## What you will leave with

Six artifacts built from your own work, and one file that travels: your **intent file**, a behavioral contract for working with AI. At the end you copy it into your own projects, and every tool you use reads it before you type a word.

## How long it takes

```
Module 00  Orientation                       about 20 minutes
Module 01  Define the work                   about an hour
           + building your intent file       about an hour, in one sitting
Module 02  Build the harness                 about an hour
Module 03  Generate broadly                  about an hour
Module 04  The seduction problem             about an hour
Module 05  Evolve deliberately               about an hour
Module 06  Your operating system             about an hour
```

About seven and a half hours in all, including the intent build. Most people spread it over two or three weeks.

You can do a module per sitting, or several. One thing not to split: the intent build. It needs a real, uninterrupted hour, and your tutor will warn you before starting it.

## Pick a project first

The course works on something real. Have one in mind before you begin: a business you are starting, a proposal, a thesis, a career move, a nonprofit initiative, a book, a product, a community event, a difficult family decision. If nothing is live for you right now, borrow one of these for the duration:

- Plan a small side business, from idea to first customer.
- Write a talk you would give to people in your field.
- Redesign how you spend your working week.
- Make the case, in writing, for a decision you keep putting off.

## The three start paths

**Start path 1: an AI tool that can read and write files.** Claude Code, Codex, Cursor, Gemini CLI, or anything similar. First get this folder onto your machine (on GitHub, the green **Code** button, then **Download ZIP**, then unzip it). Then open the folder in the tool:

- Terminal tools (Claude Code, Codex CLI, Gemini CLI): open a terminal, `cd` into the folder, and launch the tool from there with `claude`, `codex`, or `gemini`. It can see whatever folder you launched it from.
- Editor tools (Cursor, VS Code with an assistant): File → Open Folder, choose the unzipped folder, and open the assistant's chat in agent mode so it can write files.

Then type:

> Read AGENTS.md and start the course.

Your AI reads `AGENTS.md`, becomes the tutor, and asks which of three doors you want to enter by. Everything you build is written into `workbook/` automatically. If you are not sure the tool can see the folder, ask it "What files can you see?" and look for `AGENTS.md` in the answer.

**Start path 2: a browser chat.** ChatGPT, Claude.ai, or similar, with no access to your files. Open `reference/no-ai-tool-nearby.md` and follow it. You will paste lesson files in and save what comes back yourself. It works; it is just more manual.

**Start path 3: your own copy on GitHub.** Sign in to GitHub and a green **Use this template** button appears at the top of the repository page, beside **Code** (GitHub hides it when you are signed out). Click it to get a copy under your own account, then use start path 1 with that copy, and commit your workbook as you go if you like having a record. No GitHub account? The ZIP in start path 1 is the same folder.

## Coming back

Your tutor keeps `workbook/progress.md`. When you return, in this tool or a different one, it reads that file and picks up where you stopped. You never have to explain where you were.

## If something gets overwritten

Before your tutor changes any file you have built, it saves a copy in `workbook/history/` with the date and time in the name. To get an earlier version back, tell your tutor which file and roughly when, or copy the file yourself from `workbook/history/` over the live one in `workbook/`. Nothing you write in this course is ever lost by the tutor.

## The three doors

When you start, your tutor offers three doors in:

- **Door 1, start from the beginning.** The orientation, then Module 01.
- **Door 2, assess me first.** A short diagnostic conversation. Your answers place you at the right module.
- **Door 3, build my rules of interaction first.** You build your intent file straight away. How well you build it is itself the placement.

If you are not sure, say so. The tutor will suggest one.
