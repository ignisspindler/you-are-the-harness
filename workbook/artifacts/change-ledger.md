# Change Ledger
*Built in Module 05. Add an entry any time the project makes a deliberate change. New entries are added at the end; earlier ones are corrected only with a history copy first.*

```
DATE:
CHANGE:                 We changed X to Y
SOURCE:                 AI / customer / data / colleague / personal insight / this course
WHY:                    What justified this update?
WHAT REMAINS UNCHANGED: Which invariants still hold?
REVERSIBLE?             Yes / No / Partly
```

*The Source column is your accountability column. If every entry says "AI", that is a signal.*
