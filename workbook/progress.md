# progress.md

*Your tutor keeps this file. You can read it any time, and you can correct it. It is how the course knows where you are when you come back, in this tool or any other.*

*A fresh copy has every field empty except `INTENT BUILD`, which reads `not started`. That is what "new learner" looks like.*

```
ENTRY DOOR:
PLACEMENT:
CURRENT MODULE:
COMPLETED:
INTENT BUILD:         not started
ARTIFACTS BUILT:
PROJECT:
CARRY-FORWARD:
  baseline sentence:
  baseline prompt:
  M01 surprise:
  M02 operating instruction:
  M03 investigate column:
  M04 beautiful echo found:
  M05 constitution updated:
  M06 closing commitment:
LAST SESSION:
OPEN THREAD:
NEXT REAL-WORLD STEP:
```

## What the fields mean

- **ENTRY DOOR** is 1, 2 or 3, from `entry/three-doors.md`. **PLACEMENT** is the module you were placed at if you took Door 2 or Door 3, and the literal text `n/a` if you took Door 1.
- **INTENT BUILD** is `not started`, `deferred on <date>`, or `complete on <date>`. Module 00 and the entry protocol both check it.
- **CARRY-FORWARD** holds the handful of things later modules read back. The two **baseline** lines are written once, at your first contact with the course, and never changed: Module 06 measures how far you have come against them.
- **NEXT REAL-WORLD STEP** is the action you committed to take outside the chat. It is the most important line here. If it is empty when a session ends, something went wrong.

## How the tutor writes this file

`CURRENT MODULE`, `COMPLETED` and `LAST SESSION` are bookkeeping and get overwritten freely. Every other field follows the history rule: filling an empty field is fine, changing one that already has a value means a copy of this file goes to `workbook/history/` first.
